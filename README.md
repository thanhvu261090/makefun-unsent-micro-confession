One micro-confession in exactly two parts — a `To:` line and the unsent message itself — for make.fun's "Unsent: The Micro-Confession Sprint" bounty, $2 in USDC.

## The entry

> To: Mum
>
> I still rehearse telling you I dropped out in second year, then I make tea instead and ask about your garden.

## Run it

```sh
python3 main.py
```

`main.py` checks the entry against the kit gate (UTF-8 text, 1–260 characters, exactly two parts: a `To:` line and one message line of at most 200 characters) and writes it to `/output/entry.txt`.
